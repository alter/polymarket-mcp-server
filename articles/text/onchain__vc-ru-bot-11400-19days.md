# Торговый бот для Polymarket: $11,400 за 19 дней

## Архитектура: Три агента + Мета-голосование

Система включала три агента:
1. **Арбитражный агент** — поиск ценовых расхождений
2. **Конвергентный агент** — ставки на схождение вероятностей к реальным значениям
3. **Копитрейдинговый агент** — зеркалирование 47 целевых кошельков с задержкой 60 секунд

**Правило входа:**
- Если 2 из 3 агентов согласны → полная позиция
- Если 1 из 3 → половинная позиция
- Если 0 согласны → сделка не совершается

Один только этот фильтр **убрал 40% убыточных сделок**.

## Отбор кошельков для копитрейдинга

Из 14,000+ кошельков отобрано **47 самых прибыльных трейдеров** с:
- Винрейтом выше 70%
- Достаточным объёмом истории

## Результаты (19 дней)

- **214 сделок**
- Винрейт: **74%**
- Коэффициент Шарпа: **2.31**
- Итог: **+$11,400**

## Правило выхода

Главный триггер — **всплеск объёма (3× от среднего за 10 минут)**, сигнализирующий об уходе умных денег. Зашито как основное правило выхода.

Ключевое наблюдение: **91% топ-кошельков выходят из позиций до финального расчёта**, забирая в среднем 73% потенциальной прибыли.

## Что НЕ сработало

- **Спортивные рынки**: винрейт упал до 52%
- **Рынки с объёмом ниже $50K**: проскальзывание съедало прибыль
- **Удержание до расчёта**: потеря 15–30% нереализованной прибыли

## Главный урок

Мета-голосование (согласие нескольких независимых сигналов) — ключевой фильтр. Единственный источник сигнала (даже хороший кошелёк) без подтверждения хуже консенсуса трёх агентов.
