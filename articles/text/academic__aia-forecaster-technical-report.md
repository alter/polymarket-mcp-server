# AIA Forecaster: Technical Report

## Abstract

The paper presents an LLM-based system for judgmental forecasting that integrates three main components: agentic search across quality news sources, a supervisor agent for reconciling competing predictions, and statistical calibration methods to reduce LLM behavioral biases.

## Key Findings

- On ForecastBench, the system matched human superforecaster performance and exceeded previous LLM models — claimed as the first work that verifiably achieves expert-level forecasting at scale
- The forecaster underperformed market consensus independently but provided additive value when combined with market data
- The authors introduced a new, more challenging benchmark using liquid prediction market data
- Combines agentic search, supervisor reconciliation, and statistical calibration
