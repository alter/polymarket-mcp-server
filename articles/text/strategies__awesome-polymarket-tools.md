## Analytics & Data Tools

- **PolyBackTest.com**: Historical order book data, sub-second and 1-min resolution
- **PolymarketData.co**: Historical L2 depth API for execution-aware backtests
- **Dune Analytics**: SQL-queryable on-chain data (multiple dashboards)
- **Polymarket Analytics** (polymarketanalytics.com): Dashboards and data
- **Resolved Markets** (resolvedmarkets.com): Tick-level quant research + ClickHouse data
- **Polyquant.vip**: End-to-end ML pipelines (F1: 17% ROI, Weather: 2,602 markets)
- **Polyquant.pro**: Real-time event probability + automated execution

## Signal & Intelligence Tools

- **ICE Polymarket Signals** (businesswire.com): Institutional-grade signal feed (exclusive ICE partnership)
- **Alphascope.app**: AI signals across Polymarket, Kalshi, Manifold
- **YN Signals** (polymark.et): Telegram-based alerts for arbitrage, whale activity, new markets
- **Inside Edge**: AI-powered market inefficiency identification with quantified edge %
- **Polybro**: Autonomous AI trading agent with evidence-based predictions
