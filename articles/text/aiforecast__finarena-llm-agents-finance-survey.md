# Large Language Model Agents in Finance: A Survey

**Source:** ACL Anthology (EMNLP 2025 Findings)
**URL:** https://aclanthology.org/2025.findings-emnlp.972.pdf

## Summary

Comprehensive survey of LLM agents applied to financial markets, including prediction markets. Covers architectures for multi-agent financial systems, RAG-based forecasting, and human-AI collaboration frameworks.

## Key Content

- FinArena: human-AI collaboration framework with risk preference interface
- Multi-agent LLM systems simulate investment team collaboration
- TimeGPT for time series; LLaMA/GPT for text analysis; aggregated for investment decisions
- Stock-Chain: RAG-enhanced financial reasoning achieving 30.8% annualized return and 55.63% accuracy
- FinArena News Agent: adaptive RAG for news, improving relevance and factual accuracy

## Relevance to Polymarket Trading

Survey provides taxonomy of what works. Key finding: RAG-enhanced systems (Stock-Chain: 30.8% annualized return) dramatically outperform non-RAG baselines. Human-AI collaboration interfaces (FinArena) are relevant for semi-automated Polymarket trading.
