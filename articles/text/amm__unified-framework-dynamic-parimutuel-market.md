# A Unified Framework for Dynamic Pari-Mutuel Information Market Design

**Authors:** Shipra Agrawal, Erick Delage, Mark Peters, Zizhuo Wang, Yinyu Ye

**arXiv ID:** 0902.2429 | Published at EC 2009

## Abstract

Recently, several new pari-mutuel mechanisms have been introduced to organize markets for contingent claims. Hanson introduced a market maker derived from the logarithmic scoring rule, and later Chen and Pennock developed a cost function formulation for the market maker. On the other hand, the SCPM model of Peters et al. is based on ideas from a call auction setting using a convex optimization model. This work develops a unified framework that bridges these seemingly unrelated models for centrally organizing contingent claim markets. The framework supports proper scoring, truthful bidding (in a myopic sense), efficient computation, and guarantees on worst-case loss.

## Key Contributions

- Unified convex optimization framework bridging LMSR, cost-function markets, and parimutuel auction models
- Framework allows expression of various proper scoring rules from classical utility functions
- Equivalent to convex risk minimization model for the market maker, clarifying risk attitudes
- Useful cost function found in polynomial time via simple convex optimization
- Supports proper scoring, truthful bidding, efficient computation, and worst-case loss bounds

## Mechanisms Unified

| Mechanism | Key Feature |
|---|---|
| DPM (Pennock) | Dynamic prices; market maker; shares split end pool |
| LMSR (Hanson) | Derived from logarithmic scoring rule |
| SCPM (Peters et al.) | Convex optimization / call auction setting |
| Cost-Function (Chen & Pennock) | Equivalent reformulation of MSR market makers |
| Unified Framework (this paper) | Bridges all above under convex optimization |
