# Прогнозирование BTTS в футболе с ML

**Источник:** Habr.com | 2024

## Исследовательские вопросы

1. Насколько сложна задача прогнозирования BTTS?
2. Способны ли классификаторы ML прогнозировать BTTS лучше букмекеров?
3. Полезны ли ML для разработки прибыльных стратегий ставок?

## Данные

- **9 ведущих футбольных чемпионатов** (2013–2019): Англия, Испания, Германия, Италия, Франция, Нидерланды, Португалия, Бразилия A и B
- Источник: betexplorer.com (коэффициенты от 19 букмекеров)
- Разделение: 66.67% обучение (2013–2016), 33.33% тест (2017–2018)

## Инжиниринг признаков

### 1. Признаки производительности
- Среднее количество забитых/пропущенных голов
- Средние набранные очки (дома/выезд)

### 2. Последовательные признаки (цепи Маркова)
- p_yy: вероятность забить после забивания в предыдущем матче
- p_ny: вероятность забить после безголевого матча
- Аналогичные переходы для защиты

### 3. Рыночные признаки
- avg: средняя рыночная вероятность
- max/min: диапазон коэффициентов
- std: стандартное отклонение (согласованность мнений)

## Оцениваемые модели

**Базовые:** MJC (Majority Class), AMK (Average Market)

**Пуассоновские:** IPO (Maher 1982), DAC (Dixon-Coles), RAS (Rue-Salvesen Bayesian)

**ML:** Gaussian Naive Bayes, Logistic Regression, XGBoost (в 3 конфигурациях: \_P, \_M, \_A)

## Ключевые результаты

### Сложность задачи (RQ1)
- Общая доля матчей с BTTS: **50.61%** (диапазон по чемпионатам: 48–54%)
- Точность всех классификаторов лишь незначительно выше случайного (50%)
- AMK достигает только 55.34% — задача существенно сложнее, чем прогноз исхода матча

### ML vs Букмекеры (RQ2)
- XGB_M, LRE_M, GNB_M с рыночными признаками: ~55% точность = уровень AMK
- Коэффициент Каппы >0.8 между ML+market и AMK — модели воспроизводят рыночные прогнозы
- Преимущество ML: лучший **Brier Score** vs отдельных букмекеров (не рынка целиком)

### Прибыльность стратегий (RQ3)

**Наивная стратегия (NB):** Все классификаторы убыточны при ставках на все матчи.

**Стратегия ожидаемого значения (EV):** Ставить при EV > 0.

Против 1xBet (при отборе матчей по вероятностным диапазонам):
- AMK: прибыль **38.32 USD, ROI 13.53%**
- LRE_M: прибыль **61.57 USD, ROI 3.25%**

**Критическое условие:** Прибыль достигнута только при:
1. Ставках у букмекера с лучшими коэффициентами (1xBet)
2. Ограничении по диапазонам вероятностей или чемпионатам

## Ключевые выводы

1. **Рыночные признаки** содержат практически всю существенную информацию из статистических признаков
2. Неэффективность рынка ограничена — обнаружена лишь при **селективном отборе**
3. Метод Шина (1993) рекомендован для конвертации коэффициентов в вероятности
4. Стратегия "расширяющегося окна" (growing window) обеспечивает реалистичное моделирование

## Применимость к Polymarket

- Спортивные контракты с BTTS-подобной структурой (бинарный исход) поддаются аналогичному ML-анализу
- EV-фильтрация (только контракты с положительным EV) — обязательное условие прибыльности
- Выбор самого выгодного маркета (аналог 1xBet) = key для Polymarket vs Kalshi арбитража
