# Awesome Polymarket Tools

A curated list of tools, libraries, bots, and resources for the Polymarket prediction market ecosystem.

## Official Resources

- [Polymarket](https://polymarket.com/) - Official platform
- [Polymarket Documentation](https://docs.polymarket.com/) - Developer documentation and API references
- [Polymarket GitHub](https://github.com/Polymarket) - Official repositories
- [CLOB API Documentation](https://docs.polymarket.com/#clob-api)
- [Gamma API Documentation](https://docs.polymarket.com/#gamma-api)

## Browser Extensions

- **PolyPulse** - AI-powered news insights with Perplexity AI integration, auto market detection
- **Polyteller** - Essential trading tools including real-time countdowns, smart notifications
- **Polyhelper** - Enhanced Polymarket experience with countdowns, notifications, privacy features
- **Nevua Markets Plugin** - Price alerts with over/under thresholds and real-time monitoring
- **PolymarketOddsConverter** (Firefox) - Converts probabilities to decimal odds

## Productivity Extensions

- **Polymarket Extension for Raycast** - Search and view markets from Raycast with price charts

## Analytics & Tracking

### Whale Tracking

- **PolyTrack** (polytrack.org) - Comprehensive whale tracking with real-time alerts, leaderboards, P&L tracking
- **Polywhaler** (polywhaler.com) - Track $10k+ trades with insider activity detection and AI predictions
- **Poly Whales Tracker** (polywhalestracker.com) - Elite trader monitoring

### General Analytics

- **Polymarket Analytics** (polymarket-analytics.com)
- **loki.red Polymarket Stats** (loki.red/polymarket)
- **Dune Analytics** - Community dashboards for volume, open interest, user analytics
- **Bitquery Polymarket API** (bitquery.io) - Blockchain data and on-chain analytics

## Trading Bots & Automation

### Official & Featured

- [Polymarket Agents](https://github.com/Polymarket/agents) - Official AI agents framework with LLM integration
- [poly-market-maker](https://github.com/Polymarket/poly-market-maker) - Official CLOB market maker with bands or AMM strategy and Docker

### Market Making

- [poly-maker](https://github.com/warproxxx/poly-maker) - Automated MM with Google Sheets config and position merging
- [polymarket-marketmaking](https://github.com/elielieli909/polymarket-marketmaking) - Band-based MM bot

## API Libraries & SDKs

### Python

- [polymarket-apis](https://pypi.org/project/polymarket-apis/) - Unified APIs with Pydantic models for CLOB, Gamma, Data, Web3
- [py-clob-client](https://pypi.org/project/py-clob-client/) - Official Python CLOB client

### JavaScript/TypeScript Official

- [@polymarket/sdk](https://www.npmjs.com/package/@polymarket/sdk) - Official SDK for proxy wallet interactions
- [@polymarket/clob-client](https://www.npmjs.com/package/@polymarket/clob-client) - Official CLOB client
- [@polymarket/embeds](https://www.npmjs.com/package/@polymarket/embeds) - Embeddable web components

### JavaScript/TypeScript Community

- [@polybased/sdk](https://www.npmjs.com/package/@polybased/sdk) - Comprehensive TypeScript toolkit
- [@dicedhq/polymarket](https://jsr.io/@dicedhq/polymarket) - TypeScript client with CLOB and Gamma
- [polymarket-data](https://www.npmjs.com/package/polymarket-data) - Community TypeScript public data client

### AI Agent Integrations

- [@theschein/plugin-polymarket](https://www.npmjs.com/package/@theschein/plugin-polymarket) - ElizaOS agent integration
- [@goat-sdk/plugin-polymarket](https://www.npmjs.com/package/@goat-sdk/plugin-polymarket) - GOAT SDK plugin
