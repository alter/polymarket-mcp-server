# Combining and Extremizing Real-Valued Forecasts

**Authors:** Ville Satopää, Lyle Ungar
**Submitted:** June 21, 2015; revised September 25, 2015
**arXiv:** 1506.06405 [stat.ME]

## Abstract

Challenges the conventional wisdom of using weighted averages for forecast combination. "A non-trivial weighted average of different forecasts is always sub-optimal." The paper proposes linear extremization to improve weighted averages.

## Key Findings

1. **Sub-Optimality of Weighted Averaging:** Weighted averaging of forecasts (probability or real-valued) produces suboptimal results inconsistent with any proper information model about the future outcome.

2. **Information Aggregation Problem:** "Weighted averaging does not behave as if it collects information from the forecasters and hence needs to be extremized, that is, systematically transformed away from the marginal mean."

3. **Proposed Solution:** A linear extremization technique for improving the weighted average of real-valued forecasts. The resulting more extreme version exhibits properties of optimal aggregation.

4. **Practical impact:** Empirically validated on geopolitical forecasting data from the Good Judgment Project.

## Methodology

- Theoretical framework showing weighted averages fail to extract all available information
- Linear extremization technique applied to both synthetic and real GJP data
- Comparison against: raw average, log-odds average, prediction markets

## Relevance to Prediction-Market Pricing

Foundational result for any system that averages forecasts from multiple sources (models, traders, platforms). The extremization principle applies directly to aggregating probability estimates for Polymarket markets.
