# 凯利公式，从赌场到量化投资

## 简介

凯利公式（Kelly Criterion）是一种用于确定在赌博或投资中最佳投注比例的数学公式，由约翰·拉里·凯利于1956年在贝尔实验室发表。

## 核心公式

f* = (b × p - q) / b

其中：
- f* = 每次应投入的资金比例
- b = 赔率（净收益/净损失）
- p = 胜率
- q = 败率（= 1 - p）

## 从赌场到量化投资的演化

凯利公式最初被用于21点、轮盘等博弈游戏，后来被爱德华·索普率先运用于赌博和股票交易，并取得巨大成功。在量化投资中，通过前期标的的胜率、赔率来进行后续的预测，从而决定仓位或者买卖依据，是一种很正常的做法。

## 量化视角的解读

凯利公式实际上可以理解为通过胜率赔率因子的组合构建的一种组合因子，在满足特定前提下，有严格的数学基础和理论支持。

## 局限性

- 凯利公式推导中考虑的是当局数n趋近于无穷时资金量的极限特性
- 在现实中，局数n都是有限的，因此无法保证按照凯利公式下注能在有限次数内产生最高的期末资金量
- 市场的非随机性（Hurst值不等于0.5）导致计算的f值偏大

## 实际建议

许多量化交易者会使用"半凯利"（即凯利公式建议仓位的一半）来降低波动性和回撤风险，同时仍能获得较优的长期收益。
