# OctoBot Prediction Market

Free Polymarket trading robot that makes it simple and secure to automate prediction market trading strategies. GPL-3.0 licensed.

## Key Features

### Copy Trading

Replicate trades from successful Polymarket profiles to mirror their investment strategies.

### Arbitrage Opportunities

Identifies markets where buying both sides costs less than $1.00 — profits generated regardless of outcome. Core principle: if YES + NO combined cost < $1.00, guaranteed profit at resolution.

### User Interface

Dedicated interface optimized for connecting to prediction market accounts, configuring strategies, and tracking performance. Unlike Telegram-based bots, provides a proper visual UI.

### Paper Trading

Risk-free testing before deploying real capital.

### Self-Custody

Bot operates on user device — keys never leave the computer. Technically impossible for any hacker (or the OctoBot team) to access your Polymarket keys.

### Future Expansion

Kalshi support planned alongside current Polymarket integration.
