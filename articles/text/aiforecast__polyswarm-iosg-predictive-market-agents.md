# IOSG: Turning Probability into Assets — Predictive Market Agent Outlook

**Source:** PANews / IOSG Ventures
**URL:** https://www.panewslab.com/en/articles/019cb304-24a5-71ce-9864-8be61e003130

## Key Content

IOSG Ventures analysis of AI agents in prediction markets.

### Ideal Agent Architecture (4 layers)

1. **Information Layer:** Data aggregation (news, social, on-chain)
2. **Analysis Layer:** LLM + ML for mispricing detection, edge calculation
3. **Strategy Layer:** Kelly Criterion sizing, bulk building, risk control
4. **Execution Layer:** Multi-market order placement, slippage optimization, arbitrage execution

### Market Statistics

- 2025 annual prediction market volume: $40-63B (up from $9-15B in 2024)
- Kalshi + Polymarket: 97.5% market share

### Key Insight

Cross-platform arbitrage opportunity: same event priced differently across Polymarket ($0.62) and Kalshi ($0.55). Bots execute both sides when gap > transaction costs.

## Relevance to Polymarket Trading

The 4-layer architecture is a clean framework for building a full Polymarket trading agent. The Analysis Layer (LLM + ML mispricing detection) is where most value is created beyond pure arbitrage.
